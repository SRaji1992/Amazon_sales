# Amazon_sales
This excel dashboard is created to analyse and bring the insights from the amazon dataset
📊 Amazon Sales Dashboard — Excel
📌 Project Overview

This project presents an interactive Amazon Sales Dashboard built in Microsoft Excel to analyze sales performance, customer activity, product performance, order status, and payment behavior.

The dashboard transforms sales data into meaningful business insights using Excel-based data analysis and visualization techniques.

🎯 Business Objective

The main objective of this project is to analyze Amazon sales data and identify:

Overall revenue and order performance

Customer purchasing activity

Monthly sales trends

Top-performing products

Category-level performance

Order status distribution

Revenue contribution by country

Payment method performance

Cancellation and return rates

🔍 Key Insights

Based on the analysis, the following insights were identified:

May recorded the highest sales performance among the months analyzed.

The United States generated the highest total revenue among the countries in the dataset.

Australia recorded the lowest sales performance among the countries analyzed.

Among the Top 10 Products, shirts from the dress category ranked first, while the LED Desk Lamp ranked tenth.

Electronic appliances were the leading category overall, indicating strong customer demand within this category.
